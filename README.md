# 🍽️ Recipe Preparation Agent

> An intelligent, AI-powered cooking assistant that turns your available ingredients into delicious meals — powered by **IBM Watsonx.ai Granite 3** models and **Retrieval-Augmented Generation (RAG)** technology.

---

## 📋 Project Overview

The Recipe Preparation Agent helps users discover and prepare delicious meals using only the ingredients they already have at home. It reduces food waste, suggests smart ingredient substitutions, and provides personalized step-by-step cooking instructions powered by IBM's Granite AI model.

## 🏗️ Architecture

```
User Ingredients
       ↓
Sentence Transformer (all-MiniLM-L6-v2)
       ↓ Embedding
FAISS Vector Database
       ↓ Top-5 Retrieved Recipes
IBM Granite 3 Model (Watsonx.ai)
       ↓ RAG-Enhanced Prompt
Personalized Recipe + Instructions
```

### RAG Pipeline
1. **Recipe Indexing**: All recipes are embedded and stored in FAISS
2. **Query Embedding**: User ingredients are converted to vectors
3. **Semantic Retrieval**: FAISS finds top-5 most relevant recipes
4. **Context Building**: Retrieved recipes are formatted as AI context
5. **Generation**: IBM Granite generates personalized instructions

## 🚀 Installation & Setup

### Prerequisites
- Python 3.11+
- IBM Cloud account with Watsonx.ai access
- pip

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/RecipePreparationAgent.git
cd RecipePreparationAgent
```

### 2. Add More Recipes
- Place additional `*.json` recipe files into the `recipes/` folder.
- Each file should contain a JSON array of recipe objects, for example:

```json
[
  {
    "id": "pumpkin_pancakes",
    "name": "Pumpkin Pancakes",
    "cuisine": "American",
    "diet": ["Vegetarian"],
    "difficulty": "easy",
    "ingredients": ["pumpkin puree", "flour", "milk", "eggs"],
    "instructions": ["Mix ingredients.", "Cook on a griddle."],
    "prep_time": 10,
    "cook_time": 15,
    "tags": ["breakfast", "sweet"]
  }
]
```

- The app now loads all JSON files in `recipes/` automatically.
- After adding recipes, restart the app or rebuild the FAISS index:

```bash
curl -X POST http://127.0.0.1:5000/api/rebuild-index
```

### 3. Create Virtual Environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables
```bash
cp .env.example .env
```

Edit `.env` and add your IBM credentials:
```env
IBM_API_KEY=your_ibm_api_key_here
IBM_PROJECT_ID=your_ibm_project_id_here
IBM_URL=https://us-south.ml.cloud.ibm.com
MODEL_NAME=ibm/granite-3-8b-instruct
SECRET_KEY=your-strong-secret-key
```

### 5. Run the Application
```bash
python app.py
```

Open your browser at: **http://localhost:5000**

## 🎛️ Agent Customization

Edit `config.py` or `.env` to customize the agent's personality:

```env
AGENT_NAME=Chef AI
AGENT_GREETING=Hello! I'm Chef AI...
COOKING_STYLE=home-style, healthy, easy-to-follow
VEGETARIAN_PREFERENCE=suggests vegetarian options when possible
COOKING_TONE=friendly, encouraging, professional
RECIPE_DETAIL_LEVEL=detailed with clear steps, tips, and substitutions
```

Full agent instructions are in [`config.py`](config.py) → `get_agent_instructions()`.

## 📱 Usage Guide

### Searching for Recipes
1. Open the homepage
2. Type ingredients (e.g., "chicken", "tomato", "garlic")
3. Press **Enter** or click **Add** for each ingredient
4. Select cuisine, diet, and difficulty preferences
5. Click **Find Recipes with AI**

### Leftover Mode
- Enable **Leftover mode** toggle
- Add your leftover ingredients
- Get recipes that use exactly what you have

### Recipe Detail Page
- Click any recipe card to view full instructions
- ✅ Click ingredients/steps to check them off as you cook
- ❤️ Save to favorites for later
- 🖨️ Print recipe
